    Spotify-kø …

    Musiksiden kan vise næste sang og hele køen. Køen findes kun i Spotifys eget API, så du skal oprette din egen (gratis) Spotify-app én gang:

    1. Gå til developer.spotify.com/dashboard og tryk Create app.
    2. Giv den et navn (fx PhoneDeck), vælg Web API, og indsæt denne Redirect URI:
    3. Gem, og kopiér appens Client ID ind herunder.
    4. Tryk Forbind Spotify og log ind. PhoneDeck får kun lov til at læse hvad der spiller og køen.
